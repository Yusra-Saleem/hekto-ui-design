# Hekto UI Design System

> Comprehensive UI component design system and user interface showcase for Hekto.

## Overview

A dedicated design system implementation translating complex UI/UX designs into modular, reusable, and accessible React components for high-conversion e-commerce applications.

## Key Features

- Modular design tokens for typography, color palettes, and spacing scales
- Reusable atomic components: buttons, form inputs, badges, cards, and modal dialogs
- Pixel-perfect fidelity to original professional design specifications
- Fully responsive across mobile, tablet, and desktop breakpoints

## Architecture and Technology Stack

- **Core Technologies:** Next.js, React, TypeScript, Tailwind CSS, Framer Motion
- **Author:** Yusra Saleem
- **Portfolio:** [yusrasaleem.dev](https://yusrasaleem.dev)

## Getting Started

### Prerequisites

Ensure you have the required runtime environment installed for this repository:
- Node.js (v18+) for JavaScript/TypeScript projects
- Python (3.10+) for Python services and agent workflows

### Installation

Clone the repository to your local machine:

```bash
git clone https://github.com/Yusra-Saleem/hekto-ui-design.git
cd hekto-ui-design
```

Install dependencies:

```bash
# For Node / Next.js projects
npm install

# For Python projects
pip install -r requirements.txt
```

### Running Locally

```bash
# Start local development server
npm run dev

# Or for Python entry points
python main.py
```
